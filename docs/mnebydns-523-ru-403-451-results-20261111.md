# MNEBYDNS — полный RU/DE HTTP-скрининг 523 доменов, 11 ноября 2026

Источник: [полный успешный запуск GitHub Actions](https://github.com/grunvald91/telegram-proxy-infra/actions/runs/43018939131), 14 самостоятельных пакетов плюс полный контроль 523/523 без пропусков. Исходный перечень: [523 имён](../data/mnebydns-geoblock-research-20261110.tsv); в нём 506 исследовательских кандидатов и 17 справочных адресов.

Проверка: два сервера обращались к **одному и тому же публичному IPv4 оригинального сайта**, найденному с иностранной стороны, с исходными именами SNI и Host, доверенной проверкой TLS и одним HTTP GET / без логина и выполнения JavaScript. Это не тест полного сайта/приложения и **не доказательство блокировки по геолокации**: возможны WAF, автоматические антибот-фильтры и различия инфраструктуры.

## Фактические результаты

- Из РФ подтверждён HTTP **403: 152** адресов, **451: 8** адресов, итого **160**.
- Из них **111** при проверке того же исходного IPv4 с зарубежного сервера получили 2xx/3xx: более интересные кандидаты для точечной диагностики Smart DNS.
- **49** адресов из группы 403/451 не дали успешного 2xx/3xx зарубежного HTTP-ответа; их нельзя считать подтверждёнными геоблокировками.
- **109** доменов в исследовательском предварительном списке без `chatgpt.com` и `grok.com`. Это **не** означает, что они отсутствуют в действующей DNS/SNI-конфигурации — перед включением необходимо отдельно исключить все текущие активные маршруты, включая наследуемые/wildcard.
- Ни один DNS, Nginx, сервер, тариф, база данных и реальный маршрут сканированием не изменён.

## Шлюз перед добавлением

Точное имя и продукт, существующие CoreDNS/Nginx SNI и wildcard-маршруты, сертификат оригинального сервера, прохождение RU→DE ingress по TCP 443, A/AAAA/CNAME/HTTPS/SVCB, QUIC и работа на конечном устройстве. Только после этого — последовательный 60-минутный тест с откатом, проверка и явное подтверждение. **Прямое добавление CSV в живой CoreDNS недопустимо.**

## Критическое состояние: не сохранено в текущей операции

Сведения ниже — категории требуемого защищённого бэкапа, **не утверждение, что все перечисленные службы сейчас установлены**:

- PostgreSQL: база подписок, оплата, права доступа, активные пробные периоды, миграции; нужен консистентный дамп и проверяемое восстановление.
- Ключи и токены: TLS private keys, WireGuard private/preshared keys, Xray/Reality credentials и UUID, токены Telegram, провайдеров оплаты и DNS; нельзя коммитить в открытый Git.
- Серверные настройки обеих VPS: live nginx/CoreDNS, systemd unit/drop-in, WireGuard peer state, nftables/iptables, cron/timers, Docker volumes, конфиги прокси и DNS policy state.
- Состояние вне Git: пользователи и платежи в БД, VPN профили, секреты ботов, изменяющиеся файлы и runtime volumes.

**Для завершения:** сделать приватный зашифрованный offsite backup обеих VPS (в идеале и provider snapshots), отдельно PostgreSQL dump и необходимые ключи/секреты, сохранить манифест SHA-256 в закрытом хранилище, проверить восстановление на отдельном VPS/контейнере и зафиксировать время/идентификатор резервной копии. Не помещать их ни в этот публичный репозиторий, ни в GitHub Actions logs/artifacts без надлежащего шифрования и контроля доступа.

## Нельзя считать безопасным без этих проверок

- Восстановление всего сервера простым `git pull` не восстановит БД, ключи, сертификаты и Docker volumes.
- Успешный GitHub Actions backup не означает, что приватные данные попали в резервную копию.
- Не переустанавливать ОС и не удалять текущие сервисы или базы до успешного теста восстановления.
- Эксперимент v10 остаётся отключён; установка аварийной службы на живой VPS не подтверждена.

**Место хранения этой записи:** отдельная ветка `backup/pretest-2026-11-11-source` репозитория инфраструктуры; документ не создаёт никаких изменений на живых серверах.
